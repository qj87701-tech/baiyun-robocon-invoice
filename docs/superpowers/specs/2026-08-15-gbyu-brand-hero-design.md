# 广东白云学院机器人队首页品牌改版设计

日期：2026-08-15  
状态：已由用户确认  
选定方案：A「居中赛场式」

## 目标

将票据助手首页从原有 HITCRT / RoboMaster 品牌改为广东白云学院机器人队的 ROBOCON 品牌，并使用用户提供的参赛合照作为首页背景。票据识别、购买方校验、财务汇总和 XLS 导出功能保持不变。

## 品牌文案

- 浏览器标题：`广东白云学院机器人队票据助手`
- 顶部主品牌：`广东白云学院机器人队`
- 顶部副标题：`ROBOCON票据助手`
- 首页小标题：`广东白云学院机器人队 · ROBOCON`
- 首页口号：`拒绝平庸，挑战极限`
- 页脚品牌：`广东白云学院机器人队 / ROBOCON票据助手`
- 删除所有面向用户显示的 `HITCRT`、`哈工大竞技机器人队` 和 `RoboMaster` 文案。

购买方校验中的学校名称属于业务数据，不在本次品牌改版范围内。

## 主视觉

用户提供的合照将复制为站点资源 `gbyu-robocon-team.jpg`。首页继续采用居中式结构：

- 图片以 `cover` 铺满主视觉区域，桌面端背景焦点设为水平居中、垂直约 `52%`，优先同时保留队员和机器人。
- 图片上叠加横向与纵向深色渐变，保证白色口号和浅色说明在红色赛事背景上清晰可读。
- 队名、赛事名和口号保持居中，沿用现有页面的操作节奏。
- 现有黑、金、青配色继续用于导航、分隔线、按钮和数据区域，避免影响用户已经熟悉的工作区界面。
- 手机及窄屏使用相同图片，通过背景定位与最小高度控制减少人物被裁切的程度。

主视觉的记忆点是：真实参赛合照、居中的 ROBOCON 队名，以及口号“拒绝平庸，挑战极限”。

## 资源与缓存

- 新图片使用独立文件名，避免浏览器继续缓存旧背景。
- CSS 和页面脚本生成新的版本化静态资源，并由 `index.html` 引用新版本。
- 保留旧资源文件，避免仍打开旧页面的用户立即出现资源缺失。

## 不变范围

- 不修改发票 PDF/ZIP 导入。
- 不修改 OCR 与发票号码后四位识别。
- 不修改购买方校验默认值。
- 不修改财务汇总表字段、列宽和单价计算。
- 不修改 XLS 模板、字段映射与下载结果。

## 验收标准

1. 首页背景显示用户提供的广东白云学院机器人队合照。
2. 浏览器标题、顶部品牌、首页小标题、口号和页脚均使用本设计规定的新文案。
3. 页面可见文本中不存在 `RoboMaster`、`HITCRT` 或 `哈工大竞技机器人队`。
4. 桌面端与窄屏均能看清队名、ROBOCON 和口号，主要队员与机器人不被完全裁掉。
5. 个人整理和财务汇总模式可以正常切换。
6. 财务汇总仍保留八列，单价计算与 XLS 导出回归检查通过。

## 验证方法

- 在改动前先运行品牌页面自动检查，确认它因旧背景和旧文案而失败。
- 改动后运行同一检查，核对标题、文字、背景图片 URL 和页面可见性。
- 使用无界面浏览器分别截取桌面端和窄屏页面进行视觉检查。
- 运行现有财务八列表与 XLS 导出回归测试，确认品牌改版没有影响业务功能。
